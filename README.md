## Что изучено
- Метод — это именованный кусок кода, который можно вызывать сколько угодно раз; так не приходится копировать один и тот же код в несколько мест.
- void-метод просто выполняет действия (например, печатает текст), а метод с типом результата обязан вернуть значение через return, и его можно использовать в выражениях.
- Данные передаются в метод через параметры, а при вызове в них подставляются конкретные аргументы; return заодно завершает выполнение метода.
